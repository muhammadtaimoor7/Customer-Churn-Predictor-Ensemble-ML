# Customer-Churn-Predictor-Ensemble-ML
End-to-end ML project predicting telecom customer churn. Trained 5 classification algorithms and 5 ensemble methods (Voting, Bagging, AdaBoost, Gradient Boosting, Stacking), tuned with GridSearchCV. Voting Ensemble achieved the best accuracy at 82.26%, with full EDA, model comparison, and evaluation included.
